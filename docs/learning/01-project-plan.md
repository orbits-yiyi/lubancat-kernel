# 项目方案与学习方式

## 目标与约定

使用 LubanCat-1N 学习 Linux，重点放在驱动开发。用户已有 Linux 基础，希望补齐系统知识，理解每一步操作和验证方法。板上已实测为 4GB 内存、ARM64，运行 Ubuntu 20.04.6 LTS；实际运行内核版本仍需单独采集。

每次围绕一个小目标开展：先说明作用和原理，再给出少量命令，最后根据输出检查结果。源码管理、构建、烧录和驱动实验分阶段进行。

源码固定从官方 `rk356x-4.19.232-24` 起步，个人修改保存在 Fork 的 `main` 或后续实验分支中。官方标签用于查阅起点；每个实验通过 Git 提交记录变化。

后续采用 USB-OTG + Windows RKDevTool 烧录板载 eMMC。完整系统镜像、接线和设备识别在烧录课程中核对。

## 阶段安排

| 阶段 | 学习内容 | 验收结果 |
| --- | --- | --- |
| 1. 源码管理 | 仓库、分支、标签、提交、origin、upstream | 能解释当前版本，查看改动并保存一次学习记录 |
| 2. 源码与启动 | 内核目录、设备树、U-Boot、根文件系统、配置 | 能区分各组件的职责及所需构建产物 |
| 3. 构建环境 | 交叉编译、工具链、defconfig、Kbuild | 使用独立输出目录构建 -24，并保存配置和日志 |
| 4. eMMC 启动 | 完整镜像、USB-OTG、烧录工具、启动日志 | 正确识别设备，完成烧录并验证登录、网络和存储 |
| 5. 驱动基础 | 模块、字符设备、设备模型、设备树、并发 | 能编译、加载、卸载并调试一个小驱动 |
| 6. 子系统实验 | GPIO、input、I²C、SPI、UART、RTC 等 | 完成用户态访问到硬件响应的完整链路 |
| 7. 复杂外设 | MMC、USB、网络、DRM、V4L2、ALSA、DMA | 按实际外设安排专项实验 |
| 8. AI 应用 | 本地小模型、HTTP 服务、网页、systemd | 板上生成回复，网页可访问，服务可管理 |

详细实验顺序见 [驱动学习路线](03-driver-roadmap.md)。
